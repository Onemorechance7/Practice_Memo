# Practice Memo

심플하면서도 모던한 몰스킨 다이어리 감성의 메모장 앱을 위한 기본 안드로이드 프로젝트입니다.

## 주요 화면
- **메모 리스트 (첫 페이지)**: 작성된 메모를 카드 형태로 보여주며, 새로운 메모를 생성할 수 있습니다.
- **메모 편집**: 리스트에서 메모를 누르면 바로 수정 화면으로 이동합니다.

## UI 특징
- 따뜻한 베이지 톤과 블랙 컬러를 조합해 몰스킨 느낌을 반영했습니다.
- 리스트 카드에 핵심 정보를 간결하게 요약합니다.

## 실행
Android Studio에서 프로젝트를 열고 `app` 모듈을 실행하세요.
